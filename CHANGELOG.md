# Changelog

## 0.2.0 — Pure `evdev` Architecture & Gboard Bilingual Engine

### Security
- Removed unverified third-party binary auto-updater (`git.khoavo.myds.me`) and AppImage self-overwrite code from `ui/src/tray.rs`.
- Standardized purely on `systemd-logind` active-seat `uaccess` rules (`70-dboard.rules` with `MODE="0600", GROUP="root"`); removed `input` group modifications (`usermod`/`adduser`) from installer and Debian packaging.
- Rewrote AT-SPI2 password field detection (`daemon/src/password_detector.rs`) to traverse the accessible tree and check `ROLE_PASSWORD_TEXT` accurately, and extended `/proc` descendant inspection for `sudo`, `passwd`, `pkexec`, `su`, `doas`, `ssh`, `gpg`, and `cryptsetup`.
- Removed plaintext keystroke and pasted-text logging from `evdev_loop.rs` and `uinput_monitor.rs`.
- Moved daemon single-instance lockfile to `$XDG_RUNTIME_DIR/dboard-daemon.lock` so `PrivateTmp=yes` services and manual invocations share the same lock namespace.

### Added
- **Wayland Virtual Keyboard (`zwp_virtual_keyboard_v1`) Zero-Clipboard Backend (`dboard-protocol`):**
  - Persistent 8-level XKB keymap (`DBOARD_EIGHT_LEVEL`) uploaded once via `memfd_create`, mapping all 134 Vietnamese Unicode characters within safe evdev keycodes `1..=111` (eliminating Chromium/Electron DomCode collisions and clipboard churn).
  - Monotonic timestamp FIFO, Shift handoff between `zwp_virtual_keyboard_v1` and `uinput`, and Atomic Space delimiter dispatch to prevent sticky words at high WPM.
  - Chrome/Edge Omnibox Inline Autocomplete Selection Shield (`KEY_DELETE` pre-clear on both typing transforms and `Backspace` edits).
- **Gboard-inspired Dual-Hypothesis Bilingual Engine (`dboard-engine`):**
  - Preceding-word Bigram context (`LanguageContext`), retroactive 2-word disambiguation (`"Lát nữa"`, `"Lots of"`, `"Mã số"`, `"Too much"`), and Unigram collision tiers (`english_dominant_collisions` vs `vietnamese_dominant_collisions`).
  - Guarded `Backspace`-across-`Space` rehydration (`CommittedRingBuffer`) and Gboard Space-Undo after auto-restore.
  - Character-granular coda replacement on mid-word `Backspace` after free-order tone triggers (`vieetj` + `Backspace` + `c` → `việc`, `dduowngf` + `Backspace*2` + `cj` → `được`).
  - Full Telex `z` and VNI `0` tone removal, `-ươu` triphthong composition (`huouw` → `hươu`, `ruouwj` → `rượu`), free-order `qu`/`gi`/`oe` glides (`gifa` → `già`, `qusa` → `quá`, `khore` → `khỏe`, `quo7` → `quơ`, `dan9` → `đan`), and circumflex/breve/horn shape overrides (`aaw` → `ă`, `oow` → `ơ`, `a68` → `ă`, `o67` → `ơ`).
  - Expanded English double-letter (`dd`, `ee`, `oo`, `ss`, `ff`, `rr`), `w`-onset, path/URL token, and technical/early-Shift protection (`DDoS`, `add`, `wedding`, `worse`, `wonderful`, `geese`, `vieeTj` → `việt`, `u32`, `mp4`, `sha256`), plus Vietnamese `Đ/đ` abbreviation whitelist (`QĐ`, `HĐ`, `đc`, `đk`).
  - **Quantized Statistical Bilingual Language Model (`engine/src/stat_lm.rs`, `engine/src/bilingual_lm.bin`, `engine/src/ngram_lm.rs`, `engine/src/ngram_lm.bin`, `scripts/build_lm.py`):** Offline-trained 2-gram (`348 KB`) and Kneser-Ney 3-gram/4-gram (`2.63 MB`, `0.408 µs`/call) models with Next-Word Prediction (`20/20 = 100%` top-3 hit rate) and statistical retroactive 2-word code-switch disambiguation (`p50 = 1.48 µs`, `p99 = 8.04 µs`), achieving **99.92% word accuracy (99.02% sentence accuracy; 100% `pure_vn`/`pure_en`/`office`/`dev`, 95.24% `code_switch`)** across the 510-sentence bilingual benchmark.
  - **Mid-Sentence Dot-Filename Restoration (`engine/src/filename_restore.rs`):** Retroactively restores `<stem>.<ext>` and multi-dot filenames (`mở test.py`, `xem list.txt`, `sửa host.conf`, `archive.tar.gz`) without affecting Vietnamese sentence-ending periods (`"ăn bánh tét. hôm nay"`) or `CommittedRingBuffer` word boundaries.
  - **Weighted Spatial SymSpell (Telex & VNI + ~35k English), Personal Bigrams, Smart Auto-Cap & Mid-Sentence Re-Selection (`engine/src/symspell.rs`, `engine/src/user_dict.rs`):**
    - Supported Gboard-style cross-coda Telex circumflex (`khongo` → `không`, `vietej` → `việt`, `tienges` → `tiếng`, `tana` → `tân`), multi-error & missing-space SymSpell for both **Telex** and **VNI** (`khoog` / `khog6` → `không`, `khoongbieets` / `khong6biet61` → `không biết`, `xinchao2` → `xin chào`), and expanded English SymSpell (`algoritm` → `algorithm`, `tomorow` → `tomorrow`, `necesary` → `necessary`) with off-thread startup pre-warming (`dboard-warmup`) and strict zero-false-positive dev guards.
    - Added Personal Bigram adaptive learning (`bigram:<w1>|<w2>:<count>`, mode `0600`, disabled in password fields/terminals/bypass apps), `RetroactivePair` One-Tap Undo, mid-sentence caret re-selection (`tét` ↔ `test`, `lát` ↔ `last`, SymSpell fixes), and abbreviation/closing-quote Smart Auto-Capitalization.
  - **Multi-Layout Support (`protocol/src/layout.rs`, `protocol/src/wayland_vk_keymap.rs`, `engine/src/autocorrect.rs`):** Added end-to-end `KeyboardLayout { UsQwerty, Dvorak, Colemak }` (`keyboard_layout = "us" | "dvorak" | "colemak"` in `config.toml`), dynamically verified with `libxkbcommon` across all 134 Vietnamese characters and safe keycodes `1..=111`.
  - **Optional Wayland Layer-Shell Floating Candidate Strip (`ui-popup/`, `daemon/src/candidate_ipc.rs`, `ui/src/tray.rs`):** Added opt-in (`candidate_bar = false` default, 1-click **Preset: Gboard Mode / Classic Mode** in `dboard-tray`) non-blocking `O_NONBLOCK` Unix Datagram IPC (`0600`) and standalone `dboard-popup` (`zwlr_layer_shell_v1`, `KeyboardInteractivity::None`) featuring anti-aliased TrueType rendering via pure-Rust `swash` (with embedded 8×16 Vietnamese bitmap fallback), AT-SPI2 caret tracking, multi-monitor + HiDPI output mapping, mouse hover/click selection (`wl_pointer`), chained next-word prediction preserving `ring_buffer`, and tab-safe `Alt+1`/`Alt+2`/`Alt+3` selection (never hijacks browser/terminal tabs when idle or swallows empty slots; automatically hidden in password fields).

### Changed
- **Old-Style Vietnamese Tone Placement (`Kiểu cũ`):** Open diphthongs `oa`, `oe`, `uy` place tones on the first vowel (`hòa`, `khỏe`, `thủy`) and automatically shift to the second vowel when closed by a coda consonant (`hoàn`, `toán`, `huỳnh`, `tuýt`).
- Unified pure `evdev` + `zwp_virtual_keyboard_v1` / `uinput` architecture; removed all IBus, Fcitx5, Wayland IM (`zwp_input_method_v2`), X11 XRecord, `dboardctl`, `uinputd`, `vk`, `web`, and legacy PPA/AUR packaging code.
